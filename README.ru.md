# Cloudify Player

_[English version](README.md)_

Десктопный клиент для SoundCloud — лёгкий, быстрый и с настраиваемым видом.
Собран на Tauri 2 (ядро на Rust, интерфейс на React): бинарник весит несколько
мегабайт, а не тащит с собой целый браузер.

[![CI](https://github.com/solarka892/Cloudify-Player/actions/workflows/ci.yml/badge.svg)](https://github.com/solarka892/Cloudify-Player/actions/workflows/ci.yml)

> **Неофициальный клиент. Не аффилирован с SoundCloud.**
> Приложение ходит во внутренний API SoundCloud — тот же, что использует
> soundcloud.com в браузере, — потому что выдачу публичных API-ключей закрыли
> в 2015 году. SoundCloud может изменить этот API в любой момент и сломать
> приложение. **Используйте на свой страх и риск.**

## Что уже работает

- **Библиотека** — восемь разделов, в каждом свой поиск: лайки, плейлисты,
  альбомы, репосты, подписки, станции, история и загрузки.
- **Поиск** — треки, плейлисты, альбомы и люди, или всё сразу.
- **Плеер** — play/pause, перемотка, громкость и очередь: список, из которого
  вы запустили трек, становится очередью — с автопереходом, кнопками
  вперёд/назад и панелью для прыжка на любой трек. Треки, которые SoundCloud
  отдаёт только через HLS, играют наравне с остальными.
- **Звук** — десятиполосный эквалайзер с пресетами, предусиление, баланс,
  кроссфейд и выравнивание громкости.
- **Оффлайн** — скачать треки и слушать вообще без сети; приложение остаётся
  рабочим, когда вы вошли, но связи нет.
- **Полноэкранный плеер** — обложка, текст песни (из LRCLIB) и свет на выбор:
  свечение, снятое с цветов самой обложки, или обложка, размытая на всё окно.
- **Дневник** — что вы слушали, свёрнутое по дням.
- **Внешний вид** — пять скинов, семнадцать палитр, три раскладки, десять
  языков и своя рамка окна. См. [Оформление](#оформление).
- **Палитра команд** (Cmd/Ctrl-K) и горячие клавиши по всему приложению.
- **Вход** — переиспользует вашу уже открытую веб-сессию SoundCloud (см. ниже).

Сообщения и уведомления можно читать. Отправлять сообщения — нельзя: нужную для
этого ручку неофициальному клиенту звать не дают.

## Оформление

Внешний вид разложен на три независимые оси, и любое их сочетание допустимо:

- **Раскладка** — рейл с иконками, вкладки сверху или широкий сайдбар.
- **Скин** — только форма: радиус скругления, размытие, тени, шрифт, анимации.
- **Палитра** — только цвет, семнадцать штук, у каждой тёмный и светлый вариант.

В комплекте пять скинов:

| Скин | |
|------|--|
| **One** | Один шрифт, мягкие углы, тихая глубина. По умолчанию. |
| **Nit** | Две краски, квадратные карточки, круглые контролы. |
| **Editorial** | Крупная типографика, жёсткие линии, без теней. |
| **Studio** | Тактильные контролы, аккуратная глубина, волна. |
| **Obsidian** | Чёрное стекло, hairline-линии, острые края. |

**Obsidian** заходит дальше всех. Настоящий чёрный, панели светлее фона на два
процента, радиус скругления ровно ноль у всего — кнопок, обложек, аватаров, ручки
прогресса — и никакого цвета, включая артворк: обложки приводятся к одному тону,
так что яркий альбом становится фактурой, а не цветным пятном. Приложение рисует
свою полосу заголовка 32 px вместо системной, а единственный источник света —
размытая белая дуга за интерфейсом. Настройки → Оформление → **Готовые виды**
включают всё это одним нажатием.

## Установка

Готовые сборки — в [Releases](https://github.com/solarka892/Cloudify-Player/releases):

| Платформа | Файлы |
|-----------|-------|
| Linux     | `.AppImage` (портативный), `.deb`, `.rpm` |
| Windows   | `.exe` (установщик), `.msi` |
| macOS     | `.dmg` (универсальный — Apple Silicon и Intel) |
| Android   | `.apk` (Android 7+, все ABI) |

Распространяется только через релизы на GitHub — никакого App Store и Play
Store.

### Android

APK подписан, но не из Play — Android попросит разрешить установку из того
источника, откуда вы его скачали.

Вход происходит в окне внутри приложения, а не в браузере: читать cookie из
чужого профиля на Android неоткуда. Воспроизведение продолжается с выключенным
экраном, управление — на локскрине. Android 13+ спросит разрешение на
уведомления, без которого не появятся кнопки управления; сама музыка играет в
любом случае.

**Считайте это бетой.** Собирается и ставится, но обкатано заметно меньше
десктопных сборок. Подробности и известные пробелы:
[`docs/android.md`](docs/android.md).

### macOS: приложение не подписано

Подпись требует платного аккаунта Apple Developer, поэтому Gatekeeper при
первом запуске скажет, что приложение «повреждено». Это не так. Либо правый
клик по приложению → **Открыть**, либо один раз снять карантин:

```sh
xattr -cr /Applications/cloudify.app
```

### Что нужно в Linux

Звук идёт через WebKitGTK → GStreamer, поэтому нужны плагины с кодеками.
Для Arch-подобных:

```sh
sudo pacman -S --needed gst-plugins-base gst-plugins-good gst-libav
```

Токен входа хранится в системном keyring — в Linux это значит, что должен быть
запущен провайдер Secret Service (`gnome-keyring`, мост KWallet и т.п.).

## Вход и ваши данные

SoundCloud закрыл регистрацию приложений в 2015 году, поэтому реализовать
нормальный OAuth-поток не получится. Вместо этого приложение переиспользует
сессию, которая у вас уже есть:

1. **В окне, которое приложение открывает само** — настоящая страница входа
   SoundCloud в окне, cookie которого принадлежат приложению. Чужой профиль
   браузера при этом не трогается. Один раз может попросить пройти капчу —
   с этим человек справляется. **На маке это первый вариант**: там окно работает
   на WKWebView, то есть на движке самого Safari.
2. **Через браузер** — открывает soundcloud.com в браузере, которым вы и так
   пользуетесь, и читает оттуда cookie `oauth_token` после входа. Работает
   с Firefox, Zen, LibreWolf и Waterfox, а с Safari — только если дать cloudify
   полный доступ к диску; приложение показывает кнопку, которая открывает нужную
   страницу настроек. У браузеров на Chromium cookie зашифрованы ключом
   из связки ключей, поэтому они не подходят. **Первый вариант везде, кроме
   мака** — он требует от вас меньше всего.
3. **Вставить токен вручную** — скопировать `oauth_token` из DevTools браузера.
   Работает всегда, но это запасной путь, а не равноправный.

Если путь на вашей машине не сработает, приложение скажет это сразу, а не
откроет браузер и не отвалится по таймауту через три минуты.

Токен хранится в системном keyring, не в файле, и никогда не попадает в логи.
Никуда, кроме самого SoundCloud, ничего не отправляется: нет ни бэкенда, ни
телеметрии, ни аккаунта.

## Сборка из исходников

```sh
pnpm install
pnpm tauri dev      # запуск
pnpm tauri build    # установщики для текущей платформы
```

Полная настройка окружения, платформенные особенности и обход проблемы
NVIDIA/Wayland — в [docs/dev-setup.md](docs/dev-setup.md). Заметки по
реверс-инжинирингу API SoundCloud — в [docs/sc-api.md](docs/sc-api.md).

## Стек

Tauri 2 · Rust (`reqwest`, `tokio`, `keyring`) · React 18 + TypeScript · Vite ·
Tailwind CSS + shadcn/ui · Zustand

Всё, что касается SoundCloud, заперто в `src-tauri/src/sc_api/` — когда API
поменяется, чинить нужно будет ровно в одном месте.
