# Cloudify Player

_[English version](README.md)_

Десктопный клиент для SoundCloud — лёгкий, быстрый и с настраиваемым видом.
Собран на Tauri 2 (ядро на Rust, интерфейс на React): бинарник весит несколько
мегабайт, а не тащит с собой целый браузер.

[![CI](https://github.com/solarka892/Cloudify-Player/actions/workflows/ci.yml/badge.svg)](https://github.com/solarka892/Cloudify-Player/actions/workflows/ci.yml)

> **Неофициальный клиент. Не аффилирован с SoundCloud.**
> Приложение ходит во внутренний API SoundCloud — тот же, что использует
> soundcloud.com в браузере, — потому что выдачу публичных API-ключей закрыли
> в 2015 году. SoundCloud может изменить этот API в любой момент и сломать
> приложение. **Используйте на свой страх и риск.**

## Что уже работает

- **Лайки** — весь список лайкнутых треков, подгружается постранично в фоне и
  кэшируется на сессию.
- **Поиск** — поиск треков по SoundCloud.
- **Плеер** — play/pause, перемотка, громкость и очередь: список, из которого
  вы запустили трек, становится очередью — с автопереходом, кнопками
  вперёд/назад и панелью для прыжка на любой трек.
- **Внешний вид** — тёмная / светлая / системная тема, шесть акцентных цветов.
- **Вход** — переиспользует вашу уже открытую веб-сессию SoundCloud (см. ниже).

Пока нет: плейлистов, подписок, загрузок, треков только с HLS, юзеров и
плейлистов в результатах поиска.

## Установка

Готовые сборки — в [Releases](https://github.com/solarka892/Cloudify-Player/releases):

| Платформа | Файлы |
|-----------|-------|
| Linux     | `.AppImage` (портативный), `.deb`, `.rpm` |
| Windows   | `.exe` (установщик), `.msi` |
| macOS     | `.dmg` (универсальный — Apple Silicon и Intel) |

Распространяется только через релизы на GitHub — никакого App Store и Play
Store.

### macOS: приложение не подписано

Подпись требует платного аккаунта Apple Developer, поэтому Gatekeeper при
первом запуске скажет, что приложение «повреждено». Это не так. Либо правый
клик по приложению → **Открыть**, либо один раз снять карантин:

```sh
xattr -cr /Applications/cloudify.app
```

### Что нужно в Linux

Звук идёт через WebKitGTK → GStreamer, поэтому нужны плагины с кодеками.
Для Arch-подобных:

```sh
sudo pacman -S --needed gst-plugins-base gst-plugins-good gst-libav
```

Токен входа хранится в системном keyring — в Linux это значит, что должен быть
запущен провайдер Secret Service (`gnome-keyring`, мост KWallet и т.п.).

## Вход и ваши данные

SoundCloud закрыл регистрацию приложений в 2015 году, поэтому реализовать
нормальный OAuth-поток не получится. Вместо этого приложение переиспользует
сессию, которая у вас уже есть:

1. **Через браузер** — открывает soundcloud.com в вашем обычном браузере (где
   антибот-капча проходит нормально) и читает cookie `oauth_token` после того,
   как вы залогинились. Пока только браузеры на базе Firefox.
2. **Вставить токен вручную** — скопировать `oauth_token` из DevTools браузера.

Токен хранится в системном keyring, не в файле, и никогда не попадает в логи.
Никуда, кроме самого SoundCloud, ничего не отправляется: нет ни бэкенда, ни
телеметрии, ни аккаунта.

## Сборка из исходников

```sh
pnpm install
pnpm tauri dev      # запуск
pnpm tauri build    # установщики для текущей платформы
```

Полная настройка окружения, платформенные особенности и обход проблемы
NVIDIA/Wayland — в [docs/dev-setup.md](docs/dev-setup.md). Заметки по
реверс-инжинирингу API SoundCloud — в [docs/sc-api.md](docs/sc-api.md).

## Стек

Tauri 2 · Rust (`reqwest`, `tokio`, `keyring`) · React 18 + TypeScript · Vite ·
Tailwind CSS + shadcn/ui · Zustand

Всё, что касается SoundCloud, заперто в `src-tauri/src/sc_api/` — когда API
поменяется, чинить нужно будет ровно в одном месте.
